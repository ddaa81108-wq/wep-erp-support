# معاينة محلية لإعادة بناء التقارير — 24 أكتوبر 2026

## النطاق

لوحة جديدة بدأت بمعاينة محلية بجانب العرض السابق للمقارنة. لم تتغير المعاملات أو حسابات الأقسام أو سياسة التقريب أو مخطط قاعدة البيانات. أُجيز رفع التحديث إلى GitHub لاحقًا بطلب المستخدم؛ التثبيت على السيرفر يتم بأمر النشر المنفصل. بيئة العرض `http://127.0.0.1:4313/erp` تستخدم بيانات مصطنعة في الذاكرة؛ أرقامها ليست أرقام الشركة الفعلية، ولا تُضمّن بياناتها أو سكربت تشغيلها في إصدار الإنتاج. يعرض التطبيق على السيرفر بيانات مؤسسته المعتادة بعد التثبيت.

## قواعد القراءة

- مسارات جديدة `GET /api/reports/overview` و`GET /api/reports/sources?group=customers&page=1` و`GET /api/reports/activity?group=all&page=1`، جميعها تتطلب جلسة وصلاحية `reports.read`، وتُقيد النتائج بمؤسسة المستخدم.
- كل عملية قراءة تستخدم لقطة SQLite واحدة عبر `BEGIN` مؤجل؛ لا تستخدم `inImmediateTransaction` أو تهيئة حساب نقدية أو تحديث أرصدة أو إنشاء تقارير تاريخية.
- الصافي يطابق سياسة الخزينة القائمة: صافي العملاء والشركات + النقد المستقل + تحويل إجمالي المصري − صافي المشتريات والأمانات الليبية. أرصدة الحسابات الدائنة تحتفظ بإشارتها؛ هذا ليس إجمالي الديون الموجبة وحدها ولا ربحًا محاسبيًا.
- المصري من أرصدة القسم، بما فيها الحسابات المرتبطة؛ لا نضيف المصراوية وفودافون فوقها مرة ثانية. سعر التحويل والتقريب هما المعتمدان حاليًا في الخزينة. إذا كان المصري غير صفري والسعر مفقودًا يكون الصافي `null`، ولا يُختلق تحويل.
- المشتريات من باقي أحدث يوم لكل دفتر، شامل المرحّل، وليس مجموع بواقي جميع الأيام.
- التجميع بأعداد `BigInt`، مع التحقق من سلامة التحويل إلى أرقام JSON. مبالغ قيود الحسابات تقرأ من حقول المصدر الصحيحة بدل الاعتماد على حاصل ضرب SQLite المخزن في إسقاط الأستاذ. تجاوز الحد الآمن يرجع خطأ بدل رقم تقريبي.
- حركة اليوم تخص تاريخ المنظومة ومنتصف الليل وفق منطقتها الزمنية؛ لقطة الخامسة صباحًا مستقلة وتبقى بتوقيت ليبيا. لا نقفل الأقسام أو نغير تعريف أيامها.
- بند الديون اليومية يشمل الأرصدة الافتتاحية المسجلة في اليوم؛ لذلك عنوانه «ديون وأرصدة افتتاحية أُضيفت اليوم». التصحيح يحدّث القيمة الحالية والإلغاء يستبعدها؛ العرض ليس تاريخ كل تعديل.
- لا نجمع LYD وEGP في مجاميع حركة اليوم. تسديدات العملاء والشركات منفصلة عن تسديدات المشتريات وعن الدخول الفعلي للخزينة. خروج النقد لا يُسمى مصروفًا تلقائيًا.
- المعلّق والمعتمد غير المسلّم بنود متابعة، لا زيادات أخرى فوق المركز المالي. ظهور تحذير ربط تاريخي مخالف لا يصلح الرصيد تلقائيًا.
- تفاصيل المصدر 50 صفًا في الصفحة، ومجموع المصدر ثابت على كامل حساباته. تفاصيل المعاملات تعرض المصدر والموظف والتوقيت والأثر في دفتر المصدر؛ ليست مجموعًا ثانيًا للصافي.
- لقطات الخامسة المحفوظة تُقرأ كما هي؛ المقارنة مع آخر لقطة محفوظة، لا ندعي وجود لقطة لكل يوم. اللقطة الفائتة تظل فائتة؛ لا تُنشأ عند فتح الصفحة. فرق مكونات اللقطة تفسير لحركة الأرصدة وليس نسبة كل تغيير إلى عملية منفردة.

## التحديث والحدود

تتحدث اللوحة تلقائيًا بأحداث المنظومة مع تحديث زمني كل دقيقة عند ظهور الصفحة. عند الفشل تبقى آخر قراءة ناجحة مع وقتها وتنبيه، دون إعادة تحميل الصفحة أو مسح البيانات. طلب قديم لا يستبدل أحدث طلب؛ تفاصيل المصدر تحترم تبديل الاختيار والصفحات.

المصادر هي أرصدة الأقسام المعتمدة والمعاملات السارية، وليست عملية تدقيق مستقلة تعيد حساب كل دفتر. فحص المطابقة الشامل يبقى أداة منفصلة موثقة في `FINANCIAL_RECONCILIATION.ar.md`. لم تُغيّر هذه المعاينة مُجدول اللقطات القديم أو ربطه بمعاملات النظام. زر المقارنة يستدعي التقرير السابق بآليته الحالية؛ المسارات الجديدة نفسها للقراءة فقط.

## أدلة الاختبار

- `tests/report-overview.test.ts`: القراءة مع `PRAGMA query_only=ON` ومقارنة كل الجداول؛ الفصل بين العملات وغياب السعر؛ مطابقة الخزينة؛ المرحّل؛ السداد والتصحيح والإلغاء؛ المعلّق والمعتمد؛ الصلاحيات والعزل؛ حدود اليوم؛ اللقطات الثابتة والفائتة؛ الترقيم والأرصدة الدائنة؛ الأرقام التاريخية الكبيرة ورفض التجميع غير الآمن.
- `tests/report-overview-ui.ts`: مطابقة الأرقام، تفاصيل المصادر، تحديث بعد معاملة HTTP، بقاء القراءة عند فشل الشبكة، مقارنة القديم والجديد، العربية والإنجليزية، المظهران، الهاتف والكمبيوتر، وطلبات تقارير من نوع GET فقط.
- تكييف `tests/realtime-ui.ts` للتحقق من اللوحة الجديدة مع مستخدم يملك `reports.read` فقط، دون توسيع تفاصيل الأحداث المسموح بها. العرض القديم واختباراته باقية عبر زر المقارنة.
- سجلات القياس المحلية في `var/report-overview-*.log` والصور في `artifacts/report-overview/`؛ ملفات تشغيل محلية لا تُعد مرفقات نشر أو دليل اعتماد لبيانات الإنتاج.

## نتيجة التحقق المحلي

نجح `npm.cmd run check`: فحص TypeScript وESLint و204 اختبارات دون فشل أو تخطٍّ. نجح البناء ضمن حد حزمة الويب الحالي. نجحت اختبارات المتصفح للوحة الجديدة والتحديث اللحظي والعرض القديم للإقفال والفحص العام للتنقل. بعد ضبط تاريخ اللقطة ليظل بتوقيت ليبيا عند اختلاف توقيت المؤسسة، أُعيد اختبار الحالات الثماني المستهدفة ونجحت؛ لم تتغير الحسابات أو أقسام العمل بسبب هذا الضبط.
