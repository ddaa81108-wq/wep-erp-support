## 2. إنذار النسخ الاحتياطي

انتقل فحص بيانات النسخ إلى `scripts/backup-status.ps1`، ويحمّله الفحص اليومي من نفس مجلده. يجب الاحتفاظ بالملفين معًا عند نسخهما إلى جهاز آخر.

يدعم `.sqlite` و`.abdobackup` ويتجاهل الملفات المؤقتة. يتحقق من وجود ملف التعريف وصحة JSON واسم الملف والحجم وحقول حالة السلامة وتاريخ الإنشاء وشكل SHA-256. النسخة الأحدث غير المكتملة لا تُخفيها نسخة قديمة سليمة، والتاريخ المستقبلي غير المعقول لا يُعتبر نسخة حديثة.

هذا فحص **بيانات تعريف**؛ لا يفك التشفير ولا يقارن بصمة محتوى الملف في كل تشغيل يومي، ولا يحل محل فحص الاستعادة الكامل. اختبارات معزولة تغطي المجلد المفقود والفارغ، والصيغتين، والملف المؤقت، وغياب التعريف أو تلفه أو اختلاف اسمه أو حجمه، والقدم والتاريخ المستقبلي والنسخة الجديدة غير المكتملة.

أُجري الفحص المعدل على مجلد النسخ الحالي بقراءة فقط، وحُفظ التقرير في مجلد var المحلي دون استبدال التقرير التشغيلي. تعرف على النسخة المشفرة الحديثة وأعاد `OverallOk: true`. لم تُنسخ النسخ المالية أو تُحذف أو تُفك شفرتها.

## 3. محتوى إعادة إرسال الاستلام غير المرتبط

تُقارن الحقول المالية والمعنوية المخزنة — الاسم بعد تنسيق المسافات، والمبلغ، والعملة LYD — قبل إعادة الإقرار. تخزين هذه الحقول موجود أصلًا، لذا لا حاجة لجدول بصمات جديد أو تعديل الاستلامات القديمة.

- نفس المفتاح والمحتوى: نفس الاستلام وحالته؛ لا ترحيل مالي جديد.
- نفس المفتاح مع اسم أو مبلغ مختلف: 409 `REQUEST_ID_REUSED` دون تغيير الاستلام أو التدقيق أو الأحداث.
- مفتاح جديد: استلام مستقل؛ لا يُمنع تعدد الدفعات الجزئية.
- يستمر رفض أي عملة غير LYD، ومنع ربط EGP، والاعتماد الإداري قبل الأثر المالي.

تغطي الاختبارات إعادة الإقرار قبل القرار وبعد الرفض والاعتماد، وتغيير الاسم والمبلغ، وتنسيق المسافات، والمفتاح المستقل، وبقاء رصيد العميل بعد رفض طلب مخالف. لا تتغير قاعدة السداد الزائد القائمة.
