# عارض مستقل للنسخ الاحتياطية

يمكن أيضًا تشغيل `Open-Backup.cmd` بالنقر المزدوج داخل هذا المجلد.

من PowerShell:

```powershell
& 'C:\Users\Administrator\Desktop\wep-erp-support\tools\backup-viewer\Open-Backup.ps1'
```

اختر ملف النسخة. تفتح نافذة متصفح محلية لعرض الجداول، عدد السجلات، البحث، والصفحات (50 سجلًا في الصفحة). اضغط خلية لقراءة النص الطويل كاملًا. كل البيانات المعروضة خام؛ هذه أداة فحص وليست تقرير حسابات يعيد تفسير العملات والوحدات.

يدعم ملفات SQLite المستقلة، والنسخ JSON القديمة، ونسخ `.abdobackup` المشفرة. إذا وجد ملف تعريف `اسم-النسخة.json` ملاصقًا للنسخة فإنه يتحقق من بصمتها وحجمها ويرفضها عند الاختلاف. تفحص سلامة SQLite قبل العرض. لا يغير الملف الأصلي ولا يشغل خدمات المنظومة أو يستعيد بياناتها.

للنسخ المجدولة الموجودة داخل مجلد النسخ الافتراضي على السيرفر، يستخدم مفتاح الجهاز تلقائيًا إذا كان متاحًا للمستخدم الحالي. لأي نسخة أخرى تُدخل كلمة التشفير بشكل مخفي، أو تختار ملف المفتاح:

```powershell
& '.\tools\backup-viewer\Open-Backup.ps1' -BackupPath 'D:\Backups\sample.abdobackup' -KeyFile 'D:\Keys\backup-encryption.key'
```

يحتاج Node.js 24 أو أحدث، دون `npm install` أو اتصال بالإنترنت. يمكن نقل مجلد `backup-viewer` كاملًا لجهاز آخر مع Node.js والنسخة والمفتاح المناسب.

العارض يستمع على `127.0.0.1` فقط بمنفذ عشوائي ومسار سري مؤقت. لا تشارك الرابط. بعض جداول الدخول وأعمدة كلمات المرور والرموز مستبعدة؛ بقية المحتوى قد يضم بيانات عملاء أو سجلات حساسة. لا توجد كتابة SQL أو تنزيلات أو تحويلات مالية.

اضغط **إغلاق وحذف المعاينة المؤقتة** عند الانتهاء. تنتهي المعاينة تلقائيًا بعد ساعتين. يفك الملف إلى مجلد مؤقت محمي لصاحب الحساب وSYSTEM على Windows، ويفتحه للقراءة فقط. يحذف المجلد عند الإغلاق الطبيعي أو Ctrl+C؛ إغلاق العملية بالقوة أو انقطاع الكهرباء قد يترك مجلد `abdo-backup-viewer-*` في `%TEMP%` ويجب حذفه بعد التأكد أن العارض مغلق. الحذف العادي لا يضمن محوًا جنائيًا لآثار الملف من القرص.
